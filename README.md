# uniweb3k

Практические работы по веб-разработке. Одна работа — одна папка. В каждой папке есть `README.md` с объяснением кода.

| № | Папка | Тема |
|---|---|---|
| 1 | [01-bem-verstka](01-bem-verstka) | Вёрстка страницы по методологии БЭМ |
| 2 | [02-vvedenie-v-react](02-vvedenie-v-react) | Введение в React, визитка |
| 3 | [03-vvedenie-v-jsx](03-vvedenie-v-jsx) | JSX: карточка пользователя, список дел, приветствие |
| 4 | [04-struktura-proekta](04-struktura-proekta) | Структура проекта, импорт и экспорт, абсолютные пути |
| 5 | [05-sostoyanie-i-sobytiya](05-sostoyanie-i-sobytiya) | Состояние и события: трекер задач, светофор |
| 6 | [06-validaciya-formy](06-validaciya-formy) | Валидация формы, подъём состояния, аккордеон |
| 7 | [07-uslovnyj-rendering](07-uslovnyj-rendering) | Условный рендеринг, вкладки, CSS Modules |

## Как запустить

Работа 1: открыть `01-bem-verstka/index.html` в браузере.

Работы 2–7 (нужен Node.js LTS):

```bash
cd 02-vvedenie-v-react
npm install
npm run dev
```

Открыть адрес, который появится в терминале (обычно http://localhost:5173).
